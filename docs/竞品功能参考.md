# 竞品功能参考

> 本文件是 `方案设计.md` 的参考附录，记录 2026-09 对 macOS「Finder 右键增强」类产品的功能调研结果，供后续功能取舍时查阅。
>
> 覆盖 9 个产品：超级右键 iRightMouse、Menuist（原 RightMenu Master）、iBoysoft MagicMenu、MouseBoost Pro、FileUtils、Qmenu、OpenInTerminal、SaneClick、New File Menu。

---

## 一、市场格局

### 1.1 基础功能已彻底同质化

「新建文件 / 剪切粘贴 / 复制到·移动到 / 彻底删除 / 拷贝路径 / 常用目录」**六件套，四家中国产品全部具备**，差异只剩 UI 和稳定性。靠这六件事做不出差异化。

### 1.2 分化成三条路线，没有一家做全

| 路线 | 代表 | 独占能力 |
|---|---|---|
| **中文用户日常** | 超级右键 | 百度/谷歌翻译、设为壁纸、根据文件名建文件夹、隐藏扩展名批量切换 |
| **开发者 / 系统管理** | FileUtils | 图形化 ACL 编辑器 + SetUID/SetGID/Sticky 位 + 查看有效权限、文件夹比较同步、安全擦除、改文件日期 |
| **生产力工具箱** | MouseBoost Pro | 批量重命名 9 类规则、剪贴板历史、OCR（支持扫描件）、完整图片编辑、PDF 工具链 |

## 四、功能真空区（全部 11 个产品都没做）

### 4.1 操作撤销（Undo）★ 最大的体验裂缝

**没有任何一家提供。** 而市场最痛的三件事恰恰全不可逆：

- **彻底删除**——V2EX 有用户因误删、废纸篓找不回而专门发帖劝退
- **解散文件夹**——批量移动子项后原结构消失
- **剪切**——剪完粘不回去

### 4.2 文件权限的图形化编辑

只有 FileUtils 做了，且**英文界面、¥98、荷兰开发者**——中文市场完全空白。其余各家最多给一个「授予写入权限」按钮。全市场空档最大的一项。

### 4.3 批量重命名 + 图标集 + 图片工具整合

被拆散在 MouseBoost（重命名强、图片强）和超级右键（图标集强）两家，**没有一家做全**。

## 五、反直觉发现

**「剪切」可能是伪需求。** 四家花大力气做 ⌘X/⌘V，但 macOS 原生 `Command+Option+V` 就是移动，V2EX 用户自己指出了这点。用户真正要的是**「移动到…」的可见性**，而非剪切本身。FileUtils 干脆只做 copy/move，不做 cut。

**「根据文件名新建同名文件夹」性价比最高。** 只有超级右键当一等公民做，MouseBoost 仅作脚本示例。批量整理下载目录时很实用，实现简单。

**功能数量有天花板。** MouseBoost 有 60+ 功能，但 App Store 上有条评论一针见血：

> 作为键盘党，右键使用率真的不高，对我的工作效率没多大帮助

## 六、用户口碑与痛点（按频次）

### 6.1 最高频：macOS 14+ 的授权模型

所有基于 FinderSync 的产品共同面临「**开机失效 / 反复要求重新授权文件夹**」：

- Menuist 评论原话：「我都授予了全盘访问权限了，还是提示要重新授权文件夹，这个太烦了，到现在都无法解决」——**官方 FAQ 承认这是 Apple 的限制，全盘访问解决不了**
- 超级右键差评同样集中于此

### 6.2 其他高频吐槽

| 问题 | 具体 |
|---|---|
| **数据安全** | 彻底删除误删不可恢复；剪切每次请求文件夹权限、有的目录粘不过去；移动到"时灵时不灵" |
| **资源占用** | 超级右键被指活动监视器里 14 个进程费电 |
| **云盘冲突** | 影响 OneDrive 同步图标；New File Menu 在 Dropbox/OneDrive/Google Drive 常无法工作 |
| **升级失效** | New File Menu 在 Ventura/Sonoma/Sequoia 上失效报告很多 |
| **菜单臃肿** | 超级右键专业版三项翻译/二维码**强制显示不可自定义** |
| **质量问题** | MagicMenu 同一个 bug 在 App Store 被反复刷（2024/10 至 2025/08 四条雷同评论） |

### 6.3 官方承认的系统限制

- **超级右键**：macOS 14 后若"桌面/文稿"开启 iCloud 同步，Apple 禁用该类 Finder 扩展，这两个目录无法显示右键菜单
- **Qmenu**：官方明确"由于系统限制，右键菜单扩展不支持在 iCloud 等云盘文件夹里使用（包括存放在 iCloud 上的桌面和文稿文件夹）"
- **OpenInTerminal**：macOS 15+ 系统设置移除了 Finder 同步扩展配置项，必须用 `pluginkit` 手动启用

## 七、对本产品的启示

1. **不做功能军备竞赛。** 六件套已同质化，堆到 60+ 功能也换不来口碑。

2. **「撤销」是唯一能做出真差异的功能。** 我们的架构里所有写操作都走非沙盒 helper、集中在一处执行，加操作日志 + 撤销栈是自然的事。

3. **权限体验是最实的护城河。** 所有竞品差评 Top 1 都是授权问题且官方承认无解。超级右键把「一次性获取全磁盘权限」直接写成付费卖点。我们若能把这件事做顺，比加十个功能更值钱。

4. **「根据文件名新建同名文件夹」值得做。** 竞品覆盖极低、实现简单、场景明确。

5. **「剪切」优先级下调。** 原生 `Command+Option+V` 已覆盖，用户真正要的是「移动到…」的可见性。

6. **云盘目录要在产品说明里如实告知，不要藏着。** 超级右键和 Qmenu 都是官方明文承认，用户对此有预期；藏着不说会被当成 bug。
