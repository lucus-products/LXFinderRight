  <h1>LXFinderRight</h1>

macOS 的 Finder 右键增强工具。**在 Finder 空白处右键，直接新建各种格式的文件**——Markdown、文本、JSON、Word、Excel、PowerPoint……类型和顺序都能自己配，还能给自己的格式绑模板文件。

## 下载

[⬇️ 下载最新版（v0.0.1）](https://github.com/lucus-products/LXFinderRight/releases/latest/download/LXFinderRight.zip)

**安装**：解压后把 `LXFinderRight.app` 拖进「应用程序」文件夹。

> ⚠️ 本版本未做 Apple 公证，首次打开会提示「无法验证开发者」。
> 请**右键点击 App → 选择「打开」→ 再点一次「打开」**，之后就能正常双击打开了。

---

## 授权说明（重要）

本工具需要**一个**系统权限：在「系统设置 → 通用 → 登录项与扩展 → 文件提供程序」里勾选 **LXFinderRightExtension**。

勾选后如果右键菜单没出现，执行下面任一条即可：

```bash
killall Finder
```

或注销重新登录。

**不需要**「辅助功能」「完全磁盘访问」等敏感权限。

## 功能

> 当前版本只做了**右键空白处**这一条链路。右键文件/文件夹的菜单（复制路径、用终端打开等）在后续版本。

### 右键空白处 → 新建文件

在任意文件夹（含桌面）的空白处右键，选择「新建文件」，挑一个类型即可。

- 文件名默认是「未命名」，**重名自动加序号**（未命名.txt → 未命名 2.txt → 未命名 3.txt），**绝不覆盖已有文件**
- 创建后自动在 Finder 中选中
- 内置 8 种类型：Markdown / 文本 / JSON / YAML / HTML / Word / Excel / PowerPoint

### 文件类型可配置

打开 App 即可管理：

- **增删改**：加任意扩展名（`py`、`sh`、`vue`…）
- **排序**：上下移动，菜单顺序跟着变
- **启用/停用**：勾选框控制是否出现在菜单里
- **自定义模板**：给任意类型指定一个模板文件，新建时直接拷贝它

关于空白文件：
- 纯文本类（txt / md / json / yml / html…）**空文件本身就是合法的**
- Office 类（docx / xlsx / pptx）是 OOXML（zip 包），**0 字节会被 Office 判为损坏**，所以随包带了最小可用的空白模板
- 不含 `.doc` / `.xls` / `.ppt`：这几个是 OLE2 二进制格式，没法合成空白文件。需要的话自己配模板

## 已知限制

这些是 macOS 本身的限制，不是 bug：

| 限制 | 说明 |
|---|---|
| **iCloud 桌面/文稿下没有菜单** | 开启 iCloud 同步「桌面与文稿文件夹」后，Apple 禁止第三方 Finder 扩展在这两个目录工作。这是系统行为 |
| **OneDrive / Dropbox / Google Drive 等云盘目录下没有菜单** | 同上，原因一致：Finder 对每个目录只允许一个扩展接管，云盘自带扩展 |
| **外置磁盘 / 磁盘映像下没有菜单** | Finder 扩展不跨文件系统边界，当前版本只覆盖启动盘 |
| **菜单位置不可控** | 只能出现在系统指定的分组里，无法排到「新建文件夹」之前 |
| **与其他右键工具可能冲突** | 同一目录只允许一个扩展生效，如果装了同类工具，可能互相干扰 |

## 变更历史

### V0.0.1 · 首个版本

- 右键 Finder 空白处 →「新建文件」子菜单
- 内置 8 种文件类型，含可直接打开的 docx / xlsx / pptx 空白文档
- 设置界面：类型的增删改、排序、启用停用、自定义模板文件
- 重名自动加序号，绝不覆盖
- Finder 扩展只负责渲染菜单与派发，写盘由扩展内的独立逻辑完成
